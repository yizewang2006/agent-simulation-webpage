## Getting Started

### Create Your First Agent

Agents are the entities that move and interact inside the simulation.

**Step 1: Open Simulation Components**

In the **Inspector** on the right, click **Simulation Components** to view the components that can be added.

![The Inspector with Simulation Components expanded](/tutorial/create-agent-01-simulation-components.png)

*Simulation Components contains the available entity and behavior types.*

**Step 2: Open the Agent form**

Under **Entities**, select **Agent**. The Inspector will display the Agent configuration form.

![The Agent configuration form in the Inspector](/tutorial/create-agent-02-agent-form.png)

*Use this form to configure the number, spawn range, speed, heading, and field of view of the new agents.*

**Step 3: Create the Agent**

For this first Agent, keep the default settings and click **Create Agents**.

![A newly created Agent in the simulation canvas](/tutorial/create-agent-03-centered-agent.png)

**Expected result:** A new Agent appears on the simulation canvas and in the **Simulation Explorer**.
